# PROJECT SOLOSTENICS: THE GOBLIN SLAYER BIBLE (UNIFIED CANON v2.5)

## 1. Core Concept & Identity
**Name:** Project Solostenics (The Savage System)
**Core Fantasy:** The user is not playing a game — they are forcibly bound to a System that converts physical effort into power. Progress is earned through discipline.
**Mission:** A game that makes you do calisthenics (rehab) properly.

## 2. Core Gameplay Loop
- **Phase 1 (Gatekeeper/Calibration):** Ghost Overlay AR tracking.
- **Phase 2 (Exploration):** Tunnel View. Mandatory rest.
- **Phase 3 (Combat):** Doing reps deals damage. Bad reps = recoil damage.
- **Phase 4 (Tactical Rest):** Use mana to pick cards (Green: Heal, Red: Neural Override, Blue: Joint Lubrication).

## 3. The Skill Tree (Neural Map)
Progression is linear for exercises (e.g. Push-ups).
1. Wall Push-ups
2. Incline Push-ups
3. Knee Push-ups
4. Standard Push-ups
5. One-Arm Push-ups (S-Tier)

## 4. The Economy & Supply Depot
- **Iron:** Earned from doing reps. Used to buy common gear.
- **Crystals:** Premium/Rare drops.
- Items are color-coded by rarity (Common: White, Uncommon: Green, Rare: Blue, Epic: Purple, Legendary: Gold).

## 5. Monetization
- **Hunter Pass (Battle Pass):** $9.99 Premium track. Free track available. Two horizontal rows.
- **Tribute Altar:** $1 donation for OG Supporter Badge.

## 6. Daily Quests
- **Vengeance Gauge:** Fills by logging in and doing daily minimums. Fills 50% XP boost.
- **Campfire Mode:** Passive recovery and streak maintenance.
